# project-research — лабораторные по вёрстке (HTML / CSS / Bootstrap)

Каждая лабораторная лежит в отдельной папке. Чтобы посмотреть, достаточно открыть `index.html` в браузере — всё работает локально, без интернета.

| # | Папка | Задание | Технологии |
|---|-------|---------|------------|
| 1 | [`lab1-about-me`](lab1-about-me/) | Страница «About Me» | HTML, CSS |
| 2 | [`lab2-banx-layout`](lab2-banx-layout/) | Вёрстка по референсу: header, hero, блоки 2×2, карточки, footer | HTML, CSS (Flexbox), без фреймворков |
| 3 | [`lab3-sevenoaks-flexbox`](lab3-sevenoaks-flexbox/) | Вёрстка сайта SevenOaks по макету | HTML5, CSS3, Flexbox (без Grid и фреймворков) |
| 4 | [`lab4-bootstrap-banx`](lab4-bootstrap-banx/) | Страница на Bootstrap, подключённом локально из `dist/` | HTML, CSS, Bootstrap 5.3.3 |

В каждой папке есть `README.md` с описанием и чек-листом требований, а также `screenshot.jpg` с готовым результатом.

## Исходные материалы

Папка [`materials/`](materials/): тексты заданий (`docs/`), картинки (`images/`), макет лабы 3 (`lab3-design/`).
