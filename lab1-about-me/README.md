# Laboratory Work #1 — «About Me»

Простая страница о себе на HTML + CSS.

**Запуск:** открыть `index.html` в браузере.

```
lab1-about-me/
├── index.html
├── style.css
└── img/avatar.svg
```

## Чек-лист обязательных тегов

| Тег | Где используется |
|-----|------------------|
| `div` | обёртка страницы, секции, шапка |
| `h1`–`h6` | заголовки: About Me, имя, разделы, подзаголовки |
| `p`, `span`, `a` | текст, выделенное имя, ссылки GitHub / email |
| `b`, `strong`, `em`, `i` | выделения в тексте |
| `img` | фото (аватар) |
| `table`, `tr`, `th`, `td` | таблица «Education» |
| `ul`, `ol`, `li` | хобби (маркированный), цели (нумерованный) |

Дополнительно: CSS-оформление (цвета, фон-градиент, шрифты, скругления, адаптив под телефон).

> Имя, учёба и контакты — пример. Замени на свои данные в `index.html` (и фото в `img/`).
